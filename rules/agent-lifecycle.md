# 에이전트 라이프사이클 규칙

에이전트를 언제 만들고, 언제 접는가.

## 신설 판단 기준

대부분의 경우 답은 "만들지 않는다"다.

| 상황 | 판단 |
|------|------|
| 기존 에이전트 역할 범위 내 | 기존에 위임 |
| 1회성 조사/작업 | 오케스트레이터가 직접 (산출 스크립트는 일회성 규칙 적용) |
| **반복 작업 — 절차 고정·판단 불필요** | **툴/스킬 신설 (에이전트 X)** — 우선순위 게이트 |
| 반복될 패턴 + 맥락 판단 필요한 신규 영역 | **에이전트 신설** |
| 2개+ 에이전트가 겹치는 영역 | **에이전트 신설** |

3행이 가장 자주 걸린다. 절차가 고정되어 있고 판단이 필요 없다면 에이전트가 아니라 도구다.
이 게이트가 없으면 에이전트 수가 계속 늘어난다.

## 신설 프로토콜

1. 오케스트레이터가 필요성 감지
2. owner에게 **한 줄로** 제안
3. 승인 시 `agent-template.md` 기반 즉시 생성
4. 위임 테이블 업데이트
5. 첫 작업 후 피드백 반영

## 폐지 판단 기준

| 상황 | 처분 |
|------|------|
| 절차 고정·판단 불필요로 판명 | **스킬/툴로 강등** — 토큰 0, 재현성 100%, 세션 망각 없음 |
| 다른 에이전트와 같은 영역·같은 권한에서 중복 | **통합** — 분리 유지 비용이 이득을 넘음 |
| 담당 영역의 트래픽이 장기간 0 | **휴면** — 폐지 아님. 재개 시 복원 |

정의 파일은 **삭제하지 않고 `agents_archived/`로 이동**한다.
rename으로 옮기면 내용이 100% 보존되어 원본 그대로 복원할 수 있다.

> **폐지 시점에 사유를 반드시 파일에 기록한다.**
> 기록하지 않으면 나중에 열어봤을 때 왜 접혔는지 알 수 없다.
> 실제로 한 번 놓쳤고, 역산으로 메워야 했다.
> → `case-studies/agent-consolidation-22-to-17.md`

## 유형별 관리

| 유형 | 위치 | 수명 |
|------|------|------|
| 상설 | `agents/` | 영구 |
| 임시 | `agents/temp/` | 이슈 해결 시 아카이브 |
| 실험 | `agents/temp/` | 2주 후 리뷰 → 승격 or 삭제 |

## 임시 에이전트 네이밍

`agents/temp/{역할}_{YYYYMMDD}.md`
예: `agents/temp/log-anomaly-scanner_20260317.md`

날짜를 파일명에 박는 이유는 **방치를 발견하기 위해서**다.
2주가 지났는데 아직 `temp/`에 있으면 리뷰 대상이다.
## 셀프 Fix-up 규칙

> 분석형 에이전트는 작업 중 발견한 미세 문제를 직접 수정할 수 있다.
> 매번 오케스트레이터를 거쳐 수정 담당 에이전트로 재위임하는 비효율을 제거하기 위한 규칙.

운영 중 발견한 비효율을 나중에 규칙으로 승격한 것이다. 처음부터 설계한 것이 아니다.

### 대상

분석 · 감사 · 모니터링 계열 에이전트에 한정한다.
수정을 본업으로 하는 에이전트에는 적용하지 않는다.

### 조건 (모두 충족 — AND)

1. **1파일만 수정** (다중 파일 X)
2. **5줄 미만 변경** (대규모 리팩 X)
3. **Level S 파일 아님** (공용 라이브러리·클래스 등 상위 등급 경로 제외)
4. **임팩트 임계값 미만** (자체 검증 도구 기준 점수)

하나라도 걸리면 상신한다.

### 의무

- **백업 필수** — `{backup_path}/{파일명}.bak_$(date +%Y%m%d%H%M%S)`
- **작업 로그 기록** — 짧아도 되지만 반드시 남긴다
- **본인 리포트 갱신** — 최근 작업 이력에 반영
- **검증 스크립트 실행** — 해당 스택의 정적 검증 도구

### 금지

- Level S 파일 · DB 변경 · 외부 시스템 영향 → **무조건 상신**
- 셀프 fix-up 결과가 다른 영역에 영향 → 보고
- **조건 충족이 의심스러우면 → 위임 요청**

마지막 항목이 핵심이다. 기본값은 보수적이어야 한다.
애매할 때 스스로 처리하는 쪽으로 기울면 규칙 전체가 무력해진다.
